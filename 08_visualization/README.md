# Stage 8 - Circular genome visualisation (Proksee)

The circular genome map (Bari et al. 2025, Fig. 1) was generated with **Proksee
v1.0.0a6** (https://proksee.ca/).

Tracks (outer -> inner): open reading frames (tracks 1-3); CDS, tRNA, rRNA, tmRNA and
repeat regions (track 4); GC content (track 5); GC skew (track 6); remaining ORFs
(tracks 7-9). Genome size: 4,105,655 bp.

Proksee is a web service; see Fig. 1 of the publication for the rendered figure. If
exported, place the figure (PNG) here.
