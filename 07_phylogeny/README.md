# Stage 7 - 16S rRNA gene phylogeny

The 16S rRNA gene phylogeny of *A. diversa* SAU1 (Bari et al. 2025, Fig. 2) was
built as follows:

1. Related 16S sequences retrieved with **NCBI-BLAST v2.16.0**.
2. Multiple sequence alignment with **MAFFT v7.525**.
3. Tree inference by the **UPGMA** method.
4. Visualisation in **iTOL v6** (https://itol.embl.de/).

No sequence, alignment, or tree file for this step is included in this repository;
see Fig. 2 of the publication. If regenerated, place the input FASTA, alignment, and
Newick tree here (large sequence files are excluded by `.gitignore`).
