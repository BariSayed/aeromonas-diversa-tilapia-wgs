# Stage 4 - Species identification (Average Nucleotide Identity)

Taxonomic classification was performed by **Average Nucleotide Identity (ANI)** with
**JSpeciesWS** (https://jspecies.ribohost.com/jspeciesws/; Bari et al. 2025,
Methods).

[`SAU1_ANI_matrix.tsv`](SAU1_ANI_matrix.tsv) reproduces the pairwise ANI matrix from
the publication (Table 2). Strain **SAU1** shares **98.83%** ANI with the
*A. diversa* type strain CDC 2478-85 - above the 95-96% species-delineation
threshold and clearly separated from the next-closest species *A. schubertii*
(~88.8%) - confirming the isolate as ***Aeromonas diversa***.

The matrix values are quoted from the publication; JSpeciesWS is a web service and
produces no command-line output file.
